## 保持不变与边界

- 重复 id 的兼容行为、GPA `needed` 可为负的数学语义、prettier 排除范围与导出分卷规则不变。
- 澄清旧日志中的一句：显式的未加权历史 GPA 仍优先；只有未填写它时，才按已加权历史或无历史的 AP/IB 课程选择加权口径。
  以当前实现和既有回归断言为准；本轮没有更改 GPA 算法。
- 没有开始常驻文件监视，也没有改动本地 `sync.py`。副本卷被外部删除的既有运维问题不算已解决。
- 浏览器本地数据不是加密保管库；无法消除同源恶意脚本或受控浏览器读取本机存档的风险。
  真正同时写入仍不是跨标签事务；保留现有合并策略和多页面提示。
- 未进行对线上站点的破坏性攻击/压力测试，也未审计 Vercel 账户权限、平台内部或物理设备。
  “本轮已修复确认的问题”不等于“所有未来 bug 和漏洞已被证明不存在”。
