Eugene Desk Logo
================

品牌色：cream #f1ebe3 · navy #12253c · electric blue #2f6bff

文件说明
--------
eugene-desk-logo.ai / .svg / .png     横版完整 logo（已在 Illustrator 打开）
eugene-desk-mark.ai / .svg / .png     方形图标（顶栏 / favicon）
eugene-desk-logo-stacked.svg / .png   竖版完整 logo
eugene-desk-favicon.svg               小尺寸优化版
eugene-desk-favicon-1024.png          高清方形预览

在 Adobe Illustrator 2026
-------------------------
直接双击 .ai 文件，或：文件 > 打开… 选 eugene-desk-logo.ai / eugene-desk-mark.ai
（SVG 也可 File > Open）

在 Adobe Photoshop 2026
-----------------------
文件 > 打开… 选 .png 或 .svg；需要 PSD 时打开后 存储为… Photoshop (*.psd)
