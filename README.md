# 13th Desk · 尤金学生网

A hyperlocal student desk for Eugene, Oregon — K–12 (4J-centric) and UO / Lane CC.  
尤金本地学生书桌：面向 K–12（以 4J 为主）以及俄勒冈大学 / 莱恩社区学院。

**Live stack:** Vite · React · TanStack Router · Tailwind · zustand (browser-only)  
**Repo:** [9178osage/13th-desk](https://github.com/9178osage/13th-desk)

---

## English

**13th Desk** is a paper-like portal for students in Eugene: Today’s deadlines and notes, campus & town places, a short guide, and a GPA calculator. Pick your level (elementary / middle / high / uni), language, and school district. Weather comes from Open-Meteo; calendars and places are curated statically for Fall 2026 / 4J 2026–27. Notes, pins, checklist, schedule, and GPA rows stay in this browser (`13th-desk-v1`) — no account required.

### Pages
- **Today** — greeting, term day, upcoming deadlines, weather, Saturday Market, notes, pinned places, week schedule  
- **Campus** — study/dining (uni) or bells & schools (K–12)  
- **Town** — coffee, food, outdoors, errands  
- **Guide** — dates, checklist, transit, neighborhoods  
- **GPA** — level-aware calculator (UO A+=4.3; 4J weighted AP/IB/College Now)

### Run locally
```bash
cd "Eugene Student Web"   # or clone this repo
npm install
npm run dev
```
Open http://localhost:8080
